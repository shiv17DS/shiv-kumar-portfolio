# Shiv Kumar — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — dark theme, responsive layout and styling
- `script.js` — mobile navigation, active section links, current year and contact form

## Run locally
Open `index.html` in your browser. No build tools are required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `shiv-kumar-portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your live URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/shiv-kumar-portfolio/`
